# Product Template

Copy this entire `_template/` folder to create a new product:
```
cp -r products/_template/ products/<product-name>/
```

Then fill in each file with product-specific information.

## Files

| File | Purpose | When to fill |
|------|---------|-------------|
| `product-context.md` | Market, customers, constraints | First — before any other work |
| `strategy-kernel.md` | Diagnosis, guiding policy, actions | After context is established |
| `competitive-landscape.md` | Competitive positioning | During context / ongoing |
| `discovery-log.md` | Hypotheses and research findings | During Discover phases |
| `roadmap.md` | Outcome-driven roadmap | After strategy is formulated |
