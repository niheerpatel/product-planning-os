# Problem Framing

Move from discovery evidence to a bet-worthy problem statement.

## When to Use
- After validating customer problems and evidence
- Before building a solution or roadmap
- When seeking stakeholder alignment on the opportunity

## Procedure

1. Summarize the validated problem from customer evidence.
2. Define the target user and the current situation.
3. Articulate the pain point or unmet need.
4. Describe the smallest valuable outcome that would prove value.
5. Document success criteria and key assumptions.

## Output
- Clear problem statement
- Scope of the smallest valuable outcome
- Assumptions and validation plan
