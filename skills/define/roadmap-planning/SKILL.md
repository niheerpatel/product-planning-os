# Roadmap Planning

Use strategy and discovery evidence to shape a prioritized, outcome-oriented roadmap.

## When to Use
- After a strategy kernel is defined
- When turning validated problems into planned work
- When aligning stakeholders on next bets

## Procedure

1. Review the strategy kernel and discovery log.
2. Identify the highest-value opportunities.
3. Define outcomes, metrics, and time horizons.
4. Prioritize work using impact, confidence, and effort.
5. Create a roadmap that reflects the smallest valuable outcomes.

## Output
- Prioritized roadmap items
- Success metrics for each outcome
- Alignment notes and next planning steps
