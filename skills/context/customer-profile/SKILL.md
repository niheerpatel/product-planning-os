# Customer Profile

Create an evidence-based customer profile that supports sales qualification, product planning, and marketing positioning.

## When to Use
- Assessing whether a target account is healthy enough and aligned enough for partnership
- Understanding customer strategy, leadership priorities, and organizational decision dynamics
- Mapping operational problems where vendors/partners can add measurable value
- Estimating application domain fit, architecture constraints, and integration complexity
- Building a business case with production-volume and scale signals

## Procedure

### Step 1: Define Profile Scope
Clarify whether this is a named account profile or a segment profile, and what decision the profile should inform.

### Step 2: Gather Workspace Evidence
Check existing product context, discovery notes, competitive files, and customer artifacts already in the workspace.

### Step 3: Add External Evidence
Research public financials, leadership communications, technical artifacts, analyst coverage, industry reports, and operations/production signals.

### Step 4: Build Multi-Facet Profile
Cover demographics, financial health, leadership/org model, strategic direction, partner-fit challenges, application domain, software/hardware architecture signals, production volumes, and buying process.

### Step 5: Label Evidence Rigor
For each key claim, label as Evidence, Inference, or `[ASSUMPTION]` and include source, date, methodology, and confidence.

### Step 6: Translate to Action
Summarize implications for sales, product, and marketing, then identify open validation questions.

## Output
- Customer profile with objective health and direction assessment
- Structured view of partner-fit problems and where vendors can help
- Technical landscape summary including software/hardware architecture signals
- Production and scale indicators usable for business-case framing
- Evidence ledger and prioritized unknowns for next research cycle
