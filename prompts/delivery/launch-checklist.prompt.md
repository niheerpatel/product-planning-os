# Launch Readiness Checklist

Generate a comprehensive launch checklist customized to the specific product/feature being shipped.

## Output Format

# Launch Checklist: [Product/Feature]

**Target launch**: [Date]
**Launch owner**: [Name/Role]

## Product Readiness
- [ ] Core functionality complete and tested
- [ ] Known issues documented with severity ratings
- [ ] Performance benchmarks met
- [ ] Security review completed
- [ ] Accessibility requirements met
- [ ] Data privacy / compliance review completed

## Measurement Readiness
- [ ] Analytics instrumented (all key events firing)
- [ ] Dashboards created and baselined
- [ ] Alerts configured for critical metrics
- [ ] A/B test configured (if applicable)

## Customer Readiness
- [ ] Documentation / help content published
- [ ] Migration guide ready (if applicable)
- [ ] Known breaking changes communicated
- [ ] Support team briefed and trained

## GTM Readiness
- [ ] Positioning and messaging finalized
- [ ] Sales enablement materials distributed
- [ ] Partner communication sent
- [ ] Marketing assets live (blog, landing page, etc.)
- [ ] Press/analyst briefings scheduled (if applicable)

## Operational Readiness
- [ ] Rollback plan documented and tested
- [ ] On-call / incident response plan in place
- [ ] Capacity planning verified
- [ ] Monitoring dashboards active

## Go / No-Go Decision
| Criterion | Status | Owner | Notes |
|-----------|--------|-------|-------|
| ... | ✅ / ⚠️ / ❌ | ... | ... |

**Decision**: GO / NO-GO
**Rationale**: [Why]
