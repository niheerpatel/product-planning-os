# Competitive Landscape Map

Create a structured view of the competitive landscape. This identifies all relevant players, segments them by type, and maps their positioning.

## Process
1. Review any existing competitive data in the workspace
2. Identify all relevant competitors (direct, indirect, potential)
3. Segment and categorize them
4. Map positioning on key dimensions
5. Identify whitespace opportunities
