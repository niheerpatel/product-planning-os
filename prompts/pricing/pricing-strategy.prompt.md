# Pricing Strategy

Build a comprehensive pricing strategy that connects commercial model to customer value across the licensing lifecycle.

## Process
1. Review product context, competitive landscape, and any existing pricing data
2. Define the licensing journey (evaluation → production)
3. Map value propositions to personas at each phase
4. Develop sales positioning for each phase transition
5. Benchmark against competitive pricing
